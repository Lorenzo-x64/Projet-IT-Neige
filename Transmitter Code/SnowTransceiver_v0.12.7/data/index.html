About this reading

The uPesy Low-Power board has a built-in resistive divider on GPIO35 that maps the Li-Po voltage into a safe range for the ESP32 ADC. Reading uses 32-sample averaging plus a light low-pass filter to fight ADC noise.

Important: when the USB-C cable is plugged in, the divider sees V_BUS, not the battery voltage — this is detected automatically and shown as "On USB". Unplug the USB cable to read the actual battery state-of-charge.

Real Li-Po discharge curves are flat between 3.7 V and 4.0 V then drop steeply below 3.6 V — the linear approximation used here will read a few percent too low while flat, and a few percent too high near the knee. Treat the percentage as a rough indicator, not a fuel gauge.

Time-remaining estimation: the uPesy LP board has no current sensor, so we can't measure draw directly. Instead, the firmware records SoC% once per minute and runs a linear regression over the last hour to estimate the discharge rate (% per hour). Time remaining = current SoC ÷ |rate|. The estimate is unreliable until at least 5 minutes of history have accumulated, and resets every time the USB cable is connected. For a real fuel gauge, an INA219/INA226 chip wired in series with the battery would let us measure current directly — happy to add that if you ever solder one in.

Frequency & power

Channel 0 maps to 850.125 MHz; each step adds 1 MHz. EU 868 MHz uses channel 18, US 915 MHz uses channel 65 by default. Both transmitter and receiver must use the same channel.

Encryption & transmit timing
Protocol reference

The transmitter sends framed binary packets over LoRa. Receiver firmware (separate project) must parse this exact format. Each frame: 

[0xA5][VERSION=1][TYPE][LEN][SEQ_LO][SEQ_HI][PAYLOAD up to 240 B][CRC16_LO][CRC16_HI]
CRC16/CCITT-FALSE  init=0xFFFF  poly=0x1021  computed over MAGIC..PAYLOAD
  • 0x01 CSV_ROWtimestamp,distance_cm,depth_cm,outlier,event,lat,lon,alt_m,speed_kmh,sats,hdop
  • 0x02 ALERT_FALLFALL,<mag_g>,<dur_ms>,<iso8601>
  • 0x03 ALERT_IMPACTIMPACT,<mag_g>,<iso8601>
  • 0x04 ALERT_SD_FULLSDFULL,<used_pct>,<iso8601>
  • 0x05 ALERT_SENSOR_LOSTLOST,<ULTRASONIC|GPS|IMU|BATTERY>,<iso8601>
  • 0x06 HEARTBEATHB,<uptime_s>,0,<heap>,<bat_pct>

Heartbeat fires every 60 s while idle so the receiver can distinguish silent transmitter from lost transmitter.

LoRa Bands controls which regions appear in the LoRa tab

Disable bands you'll never transmit on. Hiding a band removes it from the LoRa region selector so you can't accidentally configure an out-of-region channel. At least one band must stay enabled.

Power –

Deep sleep powers the ESP32 down between samples for maximum battery life. The dashboard becomes unreachable while sleeping. Requires an interval of at least 30 seconds.

Ultrasonic Accuracy temperature compensation

The speed of sound changes with air temperature (v = 331.3 + 0.606 · T m/s). When enabled, the live distance is scaled using the AHT temperature reading so cold-weather measurements stay accurate — up to ~7 % error at −20 °C without it. For best results, set this before taring.

Fall Detection BMI160 thresholds

Free-fall fires when acceleration magnitude stays below the free-fall threshold for the sustained window. Impact fires on a single sample above the impact threshold. Cooldown is the minimum gap between any two alerts.

CSV Rotation

Choose whether all readings go into a single file or are split into separate files by date or row count. All files share the same column header so they concatenate cleanly with cat *.csv.

In the SD card preview, rows flagged as outliers (values rejected by the spike filter) are shown with a red left edge and red numbers. Turn this off if you'd rather see all rows in the same neutral style.

Set Time –

The clock is set automatically from GPS once a fix is acquired. Otherwise, push the current time from your phone or laptop so CSV timestamps match real wall-clock time.
